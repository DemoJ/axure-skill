# 能力与验证范围

适用版本：Windows / Axure RP **9.0.0.3744**。该版本依赖混淆后的私有实现，不具有官方写入 API 的跨版本兼容保证。

## 已在真实 HTML 中执行验证

| 能力 | 已验证结果 |
|---|---|
| 页面加载与跳转 | OnLoad 触发、原生跳转到另一页并返回 |
| 条件事件 | 输入为空分支与否则分支；多动作顺序执行 |
| 全局变量与表达式 | 默认值、读取/赋值、[[变量]]字符串表达式、跨页保持 |
| 动态面板 | 多状态、状态切换及淡入、嵌套面板切换 |
| 弹窗 | 初始隐藏、Lightbox 显示、关闭和显隐动作 |
| 中继器 | 多行数据、OnItemLoad/Item绑定、表达式筛选、恢复全部、数值排序 |
| 表单 | 输入、设置文本、下拉/listbox选项、初始选中、复选框勾选、禁用textarea |
| 几何和状态样式 | 移动、尺寸、百分比透明度、旋转角度、输入聚焦、鼠标悬停填充与圆角 |
| 现有原型修改 | 面板状态内文字、替换控件事件；保留页面事件及全局变量 |
| 后台导出 | Axure 原生 HTML 生成，禁止最后自动打开浏览器，源文件 hash 保持不变 |
| 编辑与演示对齐 | 原生 x=525 的390px画面留白布局与首屏打开；原生演示默认水平居中，工程/单页覆盖、旧页面 patch；1440/390/320px 与窗口缩放下可见画面位置断言，文字对齐不变 |

验证计划为 examples/advanced.test.json（16步）、controls.test.json（7步）、advanced.edit.test.json（3步）。开发环境已执行这些计划；源码仓库不包含本机报告或截图，复现时以实际生成的 runtime JSON 为证据，不能将存在测试计划本身称为通过。基础 smoke test 另外覆盖原生保存/回读、官方 API 渲染、编辑、源文件保留、拒绝覆盖、错误输入和 staging 清理。

## 已实现原生封装，尚未逐项执行

- open_url、back/reload/close、toggle、enable、scroll_to、back_order，及其他动画/窗口模式组合。
- 中继器每页条数/切页，面板 fixed/scrollbars/fit_to_content，不同状态事件。
- front、wait 在组合动作中执行过，但层级/时间没有独立断言。
- Selected、Disabled、Focused 等样式和选择组；目前实际视觉断言覆盖 MouseOver。
- 除测试样例外的扩展控件模板及其属性/事件。

这些接口会创建真实原生记录，不代表所有控件与所有参数组合均可用；使用时验证关键流程。

## 尚无完整高层接口

- 母版与复用/覆盖、Adaptive Views、团队项目/协作工程。
- 自定义图片资源导入与图片状态、SVG/自定义形状、完整富文本/阴影/渐变编辑。
- table/tree/menu 的自定义结构和数据；当前仅默认模板。
- 中继器完整布局和运行时数据增删改、拖拽相关高级配置、任意自定义事件/键盘条件组合。
- 在任意复杂现有工程中增删/重排页面、控件与状态，并证明所有其他特性无损。

已有原生模型查询、native 动作、native_model 表达式及原生属性扩展口，可在本机继续适配和验证。不能把通用扩展口描述为上述功能已经全部支持。

## 三种不同验证证据

1. **原生读写回读**：内部序列化器能保存并读取记录，文字/坐标/数据匹配。
2. **官方 API 语义读取**：另一个只读接口能加载页面、状态与控件，核对字体等；API 不暴露 repeater 项内控件。整页截图会漏画面板，不能代替浏览器检查。
3. **真实运行**：Axure 自身生成器导出 HTML，在无头浏览器执行并检查实际文本、状态、页面、数据和样式。

不使用鼠标键盘指的是不向 Windows 桌面发送输入；无头浏览器测试中的 click/fill/hover 仍是在验证真实交互。
